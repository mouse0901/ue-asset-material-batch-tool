# 资产材质批处理工具中文使用说明

这份文档是给实际使用者看的简版说明。完整说明见插件目录内的 `README.md`。

## 一句话说明

这个 UE 5.7 插件用于批量创建材质实例、绑定纹理，并把新材质实例回填到静态网格体上。

## 最常用流程

1. 选择要处理的静态网格体。
2. 打开 `资产材质批处理工具`。
3. 点击 `载入当前选择`。
4. 选择父材质。
5. 选择纹理或纹理文件夹，再点击 `载入当前选择` 或 `扫描这个目录`。
6. 点击 `生成预览`。
7. 在 `替换预览` 卡片里检查每一条结果。
8. 确认无误后点击 `执行批处理`。
9. 回到 UE 保存资产。

## 重点看哪里

预览卡片里最重要的是三项：

```text
当前材质
新材质实例
纹理绑定
```

只要这三项对，基本就可以执行。

## 注意

- 输出目录必须是 `/Game/...`。
- 不能扫描 `/Game` 根目录。
- 多材质槽模型目前默认处理 0 号槽，需要时手动改槽位。
- 执行后不会自动保存资产，需要你自己在 UE 里保存。
