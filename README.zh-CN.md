# 资产材质批处理工具

UE 5.7 编辑器插件，用于批量创建材质实例、绑定纹理，并把新材质实例回填到静态网格体材质槽。

当前版本：`v0.3.3`

## 适合解决的问题

你有一批静态网格体，每个网格体原本挂着自己的材质实例。现在需要指定一个新的父材质，再根据选中的纹理或纹理目录，批量创建新的材质实例，并自动回填到网格体上。

典型场景：

- 汽车、角色、道具资产包里，一批模型需要统一换成新的父材质实例体系。
- 纹理名称和网格体名称、当前材质名称存在对应关系。
- 需要批量生成 `M_` 前缀材质实例，并把纹理绑定到父材质真实存在的纹理参数。

## 安装方式

1. 解压插件包。
2. 把 `AssetMaterialBatchTool` 文件夹放到项目的 `Plugins` 目录。
3. 如果项目没有 `Plugins` 目录，就在 `.uproject` 同级新建一个。
4. 启动 UE 项目。
5. 如果 UE 提示需要重新编译插件，确认编译即可。

推荐目录结构：

```text
YourProject/
  YourProject.uproject
  Plugins/
    AssetMaterialBatchTool/
      AssetMaterialBatchTool.uplugin
```

## 打开工具

在 UE 内容浏览器中选择静态网格体、纹理、材质或纹理文件夹后，可以通过插件入口打开工具。

工具名称：

```text
资产材质批处理工具
```

## 推荐使用流程

1. 在内容浏览器选择要处理的静态网格体。
2. 打开插件面板，点击 `载入当前选择`。
3. 在左侧设置 `父材质`。
4. 选择纹理来源：直接选中纹理、选中纹理文件夹，或手动填写 `/Game/...` 目录后扫描。
5. 确认输出目录，例如 `/Game/Generated/MaterialInstances`。
6. 点击 `生成预览`。
7. 在中间 `替换预览` 卡片中确认每一条替换结果。
8. 如需微调，选中某条预览，在右侧 `精细调整` 中修改材质槽、实例名或输出路径。
9. 确认无误后点击 `执行批处理`。
10. 执行完成后，在 UE 中保存被修改的资产。

## 预览卡片怎么看

每条预览卡片代表一次材质实例创建和回填操作。

卡片会显示：

- `状态`：就绪、完成、警告、错误或跳过。
- `网格体`：要处理的静态网格体。
- `槽`：要回填的材质槽索引。
- `当前材质`：网格体当前槽位上正在使用的材质。
- `新材质实例`：插件将创建或更新的材质实例名称。
- `纹理绑定`：纹理会绑定到父材质的哪个参数。
- `问题说明`：匹配来源、警告或失败原因。

## 命名规则

新材质实例名称会优先根据主纹理名称生成。

```text
T_Glass -> M_Glass
TGlass  -> MGlass
Glass   -> M_Glass
```

如果名称里有非法字符，会自动替换成 `_`。

## 纹理匹配规则

当前版本的匹配优先级：

1. 当前材质名匹配纹理组。
2. 网格体名匹配纹理组。
3. 如果只有一组纹理，则使用单组纹理兜底。

插件会识别常见纹理后缀：

- BaseColor：`_BaseColor`、`_Albedo`、`_Diffuse`、`_D`、`_BC`
- Normal：`_Normal`、`_N`、`_NRM`
- ORM：`_ORM`、`_MRA`、`_Mask`
- Roughness：`_Roughness`、`_R`
- Metallic：`_Metallic`、`_Metalness`、`_M`
- Specular：`_Specular`、`_S`
- Opacity：`_Opacity`、`_Alpha`、`_A`
- Emissive：`_Emissive`、`_Emission`、`_E`

如果只提供单张纹理，插件会尝试绑定到父材质中最合理的纹理参数。

## 安全策略

- 不允许扫描空目录或 `/Game` 根目录。
- 不设置父材质时不会生成预览。
- 没有纹理来源时不会生成网格体重建预览。
- 没有匹配纹理或没有可绑定参数时，执行会跳过该行。
- 执行后资产只会标记为待保存，不会自动保存。
- 插件不会删除旧材质实例。

## 已知限制

- 当前主要面向静态网格体。
- 多材质槽目前默认处理 0 号槽，需要时手动改槽位。
- 参数映射还不是用户可编辑预设。
- 暂不自动保存资产。
